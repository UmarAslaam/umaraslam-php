(b) $getProducts = "SELECT * FROM `products`";
Database ki products table se saara data lene ke liye SQL query banayi gayi hai.

(c) $result = mysqli_query($connection, $getProducts);
mysqli_query() SQL query ko database par execute/run karta hai.

$connection → Database connection
$getProducts → SQL query
$result → Query ka result

(d) if(mysqli_num_rows($result) > 0)
mysqli_num_rows() check karta hai ke result mein kitni rows/records hain.

(e) while($row = mysqli_fetch_assoc($result))
while loop ek ek karke har product ko read karta hai.
mysqli_fetch_assoc() product ka data associative array mein deta hai.

(f) <td><?php echo $row['product_id']?></td>
Database se product ki product_id lekar table mein display karta hai.
